==========================================
PYTHON PROJECT ROADMAP: WEATHER APP
==========================================

This project is structured into 5 phases, moving from setup to advanced features.

------------------------------------------
PHASE 1: SETUP AND API ACCESS (Security Focus)
------------------------------------------

1.  SELECT API: Choose a free weather service (e.g., OpenWeatherMap, WeatherAPI).
2.  GET KEY: Register and obtain your unique API Key.
3.  SECURE CREDENTIALS:
    * Install the 'python-dotenv' library:
        $ pip install python-dotenv
    * Create a file named **.env** and place your API key inside it (e.g., API_KEY="your_secret_key").
    * Modify your script to load the key securely using 'os.getenv()'.

------------------------------------------
PHASE 2: GEOLOCATION AND DATA FETCHING
------------------------------------------

1.  GEOCoding: Implement a function to convert the **City Name** (e.g., "Paris") into **Latitude and Longitude** (Lat/Lon). Most weather services have a free Geocoding endpoint.
2.  CONSTRUCT URL: Build the final API endpoint URL using the fetched Lat/Lon and your secured API Key.
3.  REQUEST: Use the **requests** library to make a **GET** call to the weather endpoint.
4.  ERROR HANDLING: Implement robust 'try...except' blocks and check the HTTP status code (must be 200) to gracefully handle API errors or bad city names.

------------------------------------------
PHASE 3: DATA PARSING AND CONVERSION
------------------------------------------

1.  PARSE JSON: Use **response.json()** to convert the raw API data into a usable Python dictionary.
2.  EXTRACT DATA: Pull out key data points (Temperature, Humidity, Wind Speed, Weather Description).
3.  TEMPERATURE CONVERSION: Implement logic to convert the raw temperature (usually in **Kelvin**) into **Celsius** or **Fahrenheit** for user display.
4.  TIME CONVERSION: Convert Unix timestamps (if provided by the API) into readable local time strings (e.g., using Python's 'datetime' module).

------------------------------------------
PHASE 4: TKINTER GUI INTEGRATION
------------------------------------------

1.  INPUT FIELD: Create a **Tkinter Entry widget** for the user to type in the City Name.
2.  DISPLAY LABELS: Create **Tkinter Label widgets** to display the parsed weather results (e.g., one label for the city name, one for the temperature, etc.).
3.  MAIN FUNCTION: Link the **Fetch Button** command to your data fetching function from Phase 2/3.
4.  CLEAN UP: Ensure the GUI clears old results before displaying new ones.

------------------------------------------
PHASE 5: ENHANCEMENT (Visualization)
------------------------------------------

1.  FORECAST DATA: Update your API call to fetch **hourly or 5-day forecast** data.
2.  INSTALL MATPLOTLIB:
    $ pip install matplotlib
3.  PLOTTING: Use the **matplotlib** library to create a **line graph** plotting the forecasted temperature (Y-axis) against time (X-axis).
4.  EMBED PLOT: Use the **FigureCanvasTkAgg** component from the matplotlib backend to embed the generated chart directly into your existing Tkinter window, providing a rich, visual forecast view.
